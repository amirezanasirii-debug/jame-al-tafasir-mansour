# اندروید منصور ۲.۸ — پیش‌نمایش ۱

همان فایل‌های `dist/research.*` در Windows و Android استفاده می‌شوند. APK شامل تمام داده‌های بستهٔ میز پژوهش است و مطالعه به اینترنت وابسته نیست. شناسهٔ برنامه `org.jamealtafasir.mobile`، versionCode برابر 20799 و حداقل Android برابر 7 است. Android System WebView باید مبتنی بر Chromium 111 یا بالاتر باشد. این APK نسخهٔ پیش‌نمایش انتشار مستقیم است، نه بستهٔ آمادهٔ Google Play.

پوسته بر پایهٔ سورس انتشار ۲.۷ پروژه و AGP 8.13.2 / Gradle 8.13 / JDK 17 / SDK 36 ساخته شده است. کلید امضای موجود پروژه استفاده شده؛ کلید یا رمز در این بسته نیست. اثرانگشت SHA-256 گواهی:

`ecde148bd8ad34be6148731c888228920772364ab79fa8de24046c8bab706d73`

گواهی با APK محلی نسخهٔ ۲.۴ تطبیق داده شد. روی نسخه‌ای با همین شناسه و گواهی، نصب به‌صورت ارتقا امکان‌پذیر است. یادداشت‌های میز پژوهش کلید ذخیره‌سازی جدا دارند؛ مهاجرت خودکار یادداشت‌های محیط قدیمی پیاده‌سازی نشده است. قبل از ارتقا پشتیبان بگیرید. برای بازگشت از پیش‌نمایش به نسخهٔ قدیمی ممکن است حذف برنامه لازم شود؛ این کار داده‌های محلی را پاک می‌کند.

## ساخت از سورس کامل انتشار

مقدار `JAVA_HOME` و `ANDROID_HOME` را برای ابزارهای نصب‌شده تعیین کنید. چهار متغیر `JAME_KEYSTORE_PATH`، `JAME_KEYSTORE_PASSWORD`، `JAME_KEY_ALIAS` و `JAME_KEY_PASSWORD` باید به کلید بیرون مخزن اشاره کنند. کلید تازه برای ارتقای نسخهٔ قبلی سازگار نیست.

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm run build
./gradlew.bat --no-daemon --no-configuration-cache :android:assembleDirectRelease :android:lintDirectRelease
```

خروجی در `android/build/outputs/apk/direct/release/android-direct-release.apk` است. دانلود اولیهٔ ابزارها به اینترنت نیاز دارد؛ خود برنامه نیاز ندارد. استفاده از mirror اختیاری با `-Pjame.googleMavenMirror=https://maven.aliyun.com/repository/google` ممکن است؛ فایل‌های کش‌شدهٔ ساخت محلی از همین mirror بودند.

## رفتارهای ویژهٔ اندروید

- ذخیرهٔ JSON و Markdown از انتخابگر فایل Android؛ بدون مجوز عمومی دسترسی به حافظه.
- ورود پشتیبان از انتخابگر فایل و ادغام با یادداشت‌ها.
- کپی متن با ارجاع از طریق ClipboardManager.
- پخش صوت محلی با پشتیبانی Range و نگهداری MP3 بدون فشرده‌سازی داخل APK.
- بازگشت از نتایج جست‌وجو و بخش‌های دیگر به مطالعه، سپس خروج.
- نمایش تأیید حذف یادداشت با پنجرهٔ بومی.

شبکهٔ WebView به میزبان مصنوعی محلی محدود است؛ دادهٔ HTML منابع به متن تبدیل می‌شود، iframe مسدود است و bridge فقط عملیات محدود ذخیرهٔ سند و کپی متن دارد. محتویات فایل‌های انتخاب‌شده به‌عنوان کد اجرا نمی‌شوند.

## دامنهٔ آزمون

آزمون‌های داده و رابط دسکتاپ، آزمون نمای موبایل ۳۹۰ پیکسل با bridge شبیه‌سازی‌شده، lint اندروید، صحت امضای APK و موجودبودن داده‌های بسته بررسی می‌شوند. دستگاه یا شبیه‌ساز Android متصل نبود؛ انتخابگر فایل، صدای دستگاه و نصب ارتقایی هنوز روی دستگاه واقعی آزموده نشده‌اند. گزارش‌های همراه، دامنهٔ هر آزمون را مشخص می‌کنند.
