# جامع التفاسیر منصور — میز پژوهش ۲.۸ (پیش‌نمایش)

این خروجی یک نسخهٔ ترکیبی قابل اجرا برای بازبینی است، نه اعلام تکمیل تمام امکانات جامع‌التفاسیر نور یا انتشار نهایی تجاری. نصب اصلی منصور و نور تغییر نکرده است.

## اجرا

نسخهٔ Android امضاشده نیز در انتشار ۲.۸ پیش‌نمایش ارائه می‌شود؛ راهنمای ساخت و محدودیت آزمون دستگاه در [ANDROID_BUILD.md](ANDROID_BUILD.md) است. برای استفاده از APK نیازی به Node.js نیست.

در پوشهٔ `Mansour-Research-Portable` فایل `Jame al Tafasir Mansour.exe` را اجرا کنید. کل پوشه باید همراه برنامه بماند؛ کپی‌کردن EXE به‌تنهایی کافی نیست. اینترنت و نصب Node.js برای نسخهٔ Portable لازم نیست. نام فایل اجرایی از محیط اجرایی نصب‌شدهٔ خودتان حفظ شده؛ عنوان داخل برنامه «میز پژوهش» است.

## امکانات ترکیبی

- شش رنگ‌بندی ذخیره‌شونده: سبز، آبی، کرم، ارغوانی، شب و کنتراست بالا؛ تنظیم فاصلهٔ خطوط و چیدمان کنار هم یا قرآن بالا/تفسیر پایین.
- فیلتر زبان و موضوع کتابخانه، مرتب‌سازی عنوان و نویسنده، رفتن مستقیم به جزء و صفحهٔ قرآن.
- آیات مرتبط از بستهٔ آفلاین موجود، جست‌وجوی پیوندها و رفتن مستقیم به آیه؛ جزئیات تطبیق نمونه‌ای با سایت در `WEB_REVIEW.md`.

- محیط فارسی راست‌به‌چپ تازه، حالت شب، اندازهٔ قلم و میان‌بر Ctrl+K برای جست‌وجو.
- متن موجود قرآن: ۱۱۴ سوره، ۶۲۳۶ آیه؛ بدون بازنویسی متن منبع.
- ترجمهٔ رواد و سه ترجمهٔ خوانده‌شده از بانک نور، با انتخاب منبع.
- مقایسهٔ میسر و پنج بستهٔ تفسیری موجود در منصور. بسته‌ها گزیده هستند و پوشش کامل هر آیه تضمین نشده است.
- فهرست واقعی ۹۰۳ مجموعهٔ نور، با نویسنده، ناشر و موضوع. این فهرست به معنی همراه‌بودن متن کامل همهٔ کتاب‌ها نیست.
- نمایش ارجاعات تفسیری نور با نام کتاب، جلد و صفحه، متصل به سوره/آیه.
- کتاب‌خوان ۲۰ جلد المیزان موجود در منصور؛ صفحه در این بخش، شمارهٔ PDF است.
- احادیث موجود در بستهٔ منصور و ۱۱۴ فایل صوتی محلی منشاوی.
- جست‌وجوی بدون حساسیت به اعراب و ی/ک در قرآن، رواد و میسر؛ جست‌وجوی تمام کتاب‌ها هنوز اضافه نشده است.
- یادداشت و نشان آیه، پشتیبان JSON، بازیابی با ادغام و خروجی Markdown. یادداشت‌ها مستقل از نسخهٔ قبلی ذخیره می‌شوند.
- محیط قبلی منصور با تمام فایل‌های بسته‌اش از منوی «منصور» قابل بازشدن است. ارتباط اینترنتی این نسخه برای آفلاین‌بودن بسته شده؛ امکانات آنلاین محیط قبلی کار نمی‌کنند.

## وضعیت سورس

در مرحلهٔ انتشار ۲.۸، مخزن گیت‌هاب پروژه و سورس ضمیمهٔ انتشار ۲.۷ پیدا و بررسی شد. پوستهٔ Android این خروجی بر پایهٔ سورس انتشار ۲.۷ است. میز پژوهش به‌صورت افزودهٔ مستقل در پوشهٔ `research` مخزن منتشر می‌شود؛ کد جدید جای تمام کدهای قبلی را نگرفته است.

دو آرشیو نسخهٔ ۲.۴ ارسالی فقط README داشتند. از نسخهٔ نصب‌شده، بستهٔ `app.asar` بازیابی و فایل‌های آن با هش‌های درون آرشیو کنترل شد. فایل‌های کامپایل‌شدهٔ قبلی در `dist/assets` و داده‌ها نگه داشته شده‌اند؛ این‌ها جای سورس اصلی React/TypeScript را نمی‌گیرند. کد جدید میز پژوهش در `dist/research.mjs`، `dist/research-core.mjs`، `dist/research.css` و `dist/research.html` خوانا و قابل ویرایش است. پوستهٔ دسکتاپ جدید در `desktop/main.cjs` است.

## تست و ساخت

با Node.js 24.20 و pnpm 11.25 بررسی شده است:

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm run build
```

پروژهٔ بازیابی‌شده وابستگی نصب‌شدنی ندارد؛ `build` صحت داده‌ها را بررسی می‌کند و `BUILD_REPORT.json` می‌سازد. این دستور کامپایل مجدد React قبلی یا تولید نصب‌کننده نیست. برای اجرای سورس با Electron باید محیط اجرایی Electron جداگانه فراهم باشد. نسخهٔ Portable تحویلی از محیط اجرایی نصب‌شدهٔ منصور شما ساخته شده است.

برای تازه‌سازی داده‌های نور، با Node.js دارای `node:sqlite`:

```powershell
node scripts/import-noor.mjs "C:/ProgramData/Noor/JamiTafasir4"
```

اسکریپت فقط جداول منتخب را با اتصال read-only می‌خواند و JSON را در `dist/research-data` می‌سازد. بانک اصلی را تغییر نمی‌دهد. انتقال مجدد نیازمند منبع داده و مجوز مربوط است.

## محدودیت‌ها و ادامهٔ کار

نصب‌کننده، امضای دیجیتال، مهاجرت یادداشت‌های قدیمی، ریشه‌شناسی/صرف/نحو، واردکنندهٔ عمومی بستهٔ تفسیر و جست‌وجوی جامع تفاسیر هنوز تکمیل نشده‌اند. برای توسعهٔ پایدار بهترین گام بعدی دریافت سورس اصلی منصور و انتقال کد تازه به ساختار آن است. آزمون روی دستگاه Windows پاک و بازبینی علمی/مجوز بسته‌های محتوا پیش از انتشار عمومی باقی است. هیچ متن تفسیری یا تحلیل هوش مصنوعی در این نسخه تولید نشده است.

ذخیره‌سازی عادی برنامه در `%APPDATA%/MansourResearchPreview` است. برای انتقال یادداشت‌ها از دکمهٔ پشتیبان JSON استفاده کنید.

## ساخت از checkout گیت
