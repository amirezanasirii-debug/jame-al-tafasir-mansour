# جامع‌التفاسیر منصور

برنامه‌ای مستقل برای مطالعه و پژوهش قرآن در Windows و Android؛ با رابط فارسی راست‌به‌چپ، مطالعهٔ آفلاین، جست‌وجو، یادداشت، نشان‌گذاری و کتابخانهٔ منبع‌محور.

## محتوای نسخهٔ پایه

- متن عثمانی قرآن Tanzil نسخهٔ 1.1؛ عین متن و بدون تغییر.
- ترجمهٔ فارسی مرکز رواد و `التفسير الميسر` از QuranEnc، با حفظ نسخه و انتساب.
- چهار بستهٔ تفسیری منتخب و آفلاین: ترجمهٔ المیزان، برگزیدهٔ نمونه، ترجمهٔ مجمع‌البیان و نورالثقلین؛ سوره‌به‌سوره و همراه مشخصات مؤلف/ناشر.
- سه فونت آفلاین دارای SIL Open Font License.
- رابط، کد، آیکن و ساختار دادهٔ هیچ نرم‌افزار دیگری بازسازی نشده است؛ بسته‌های علمی با منشأ و انتساب مستقل نگهداری می‌شوند.

جزئیات منشأ و شرایط استفاده در [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md) و مجوز فونت‌ها در [docs/LICENSES.md](docs/LICENSES.md) ثبت شده است.

## امکانات

- فهرست ۱۱۴ سوره و ۶٬۲۳۶ آیه، نمایش صفحه‌ای و آیه‌به‌آیه.
- جست‌وجوی نرمال‌شده در قرآن، ترجمه و تفسیر نصب‌شده و پرش مستقیم مانند `۲:۲۵۵`.
- مشابه‌یاب واژگانی آفلاین با اعلام روشن اینکه نتیجه، رابطهٔ تفسیری یا روایی قطعی نیست.
- آخرین جای مطالعه، نشان‌ها با دسته‌بندی و یادداشت پژوهشی غنی.
- خروجی و ورودی JSON برای داده‌های شخصی؛ بدون بارگذاری ابری خودکار.
- انتخاب فونت و اندازهٔ قرآن، تم روشن/تاریک و رابط واکنش‌گرا.
- کتابخانهٔ تفاسیر منتخب با بارگذاری کم‌حافظهٔ سوره‌ای و مطالعهٔ کاملاً آفلاین.
- رابط شیشه‌ای مستقل سبز زمردی و طلایی با fallback سبک برای دستگاه‌های فاقد blur.
- پوستهٔ بومی Android با Jetpack Compose برای TopBar، BottomBar پنج‌تب و Drawer شیشه‌ای.

## توسعه و آزمون

پیش‌نیاز: Node.js 22 و pnpm.

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm run build
```

اجرای محلی:

```powershell
pnpm start
```

## ساخت Windows

```powershell
pnpm run package:windows
```

خروجی NSIS در `release/` ساخته می‌شود. بدون گواهی Authenticode معتبر، حذف کامل هشدار SmartScreen قابل تضمین نیست.

## ساخت Android

راهنمای کامل در [docs/ANDROID_BUILD.md](docs/ANDROID_BUILD.md) است. ساخت Release بدون کلید امضای خارجی عمداً متوقف می‌شود:

```powershell
pnpm run package:android
```

کلید، رمز یا توکن نباید داخل مخزن قرار گیرد.

## حریم خصوصی

یادداشت‌ها، نشان‌ها، تاریخچهٔ جست‌وجو و تنظیمات روی همان دستگاه ذخیره می‌شوند. برنامه در نسخهٔ فعلی دادهٔ شخصی را به سرور ارسال نمی‌کند.

## وضعیت حقوقی

کد رابط و امکانات برنامه متعلق به پروژه است؛ حق هر متن، ترجمه، تفسیر، فونت و داده متعلق به پدیدآورنده یا منبع ثبت‌شدهٔ خودش باقی می‌ماند. وجود یک مخزن عمومی یا API به‌تنهایی به معنی مجوز بازتوزیع محتوا نیست.
