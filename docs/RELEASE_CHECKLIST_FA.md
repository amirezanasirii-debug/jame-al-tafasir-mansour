# چک‌لیست انتشار جامع‌التفاسیر منصور ۲.۵.۰

**وضعیت: نسخه توسعه‌ای؛ انتشار عمومی ممنوع تا تکمیل همه موارد.**

## اندروید
- [ ] موفقیت GitHub Actions برای آخرین Commit
- [ ] تأیید شناسه بسته (applicationId) نسخه ۲.۴.۰ با APK اصلی؛ شناسه فعلی سورس صرفاً فرض اولیه است
- [ ] امضای نسخه Release با کلید خصوصی متعلق به مالک پروژه؛ هرگز کلید را در GitHub ثبت نکنید
- [ ] تست نصب تمیز، ارتقا از ۲.۴.۰، بازیابی داده‌ها و تست آفلاین
- [ ] تست واردکردن SQLite معتبر و نامعتبر و پایداری رابط کاربری

## ویندوز
- [ ] موفقیت CI و آزمون‌های SQLite
- [ ] اجرای واقعی EXE در ویندوز ۱۰ و ۱۱
- [ ] آزمایش بسته داده، جستجو و متن‌های راست‌به‌چپ
- [ ] امضای کد در صورت امکان و بررسی هش SHA-256

## داده و محصول
- [ ] بررسی مجوز انتشار متن قرآن و هر ترجمه و تفسیر
- [ ] بررسی صحت قرآن با منابع معتبر مستقل
- [ ] تکمیل قابلیت‌های وعده‌داده‌شده نسخه ۲.۴.۰ یا مستندسازی تغییرات ناسازگار
- [ ] تأیید رابط کاربری، دسترس‌پذیری، امنیت و عملکرد

## انتشار
- [ ] انتشار پیش‌نسخه جداگانه (pre-release) فقط بعد از ساخت و آزمایش موفق
- [ ] انتشار Release نهایی تنها پس از تأیید همه مراحل و بارگذاری SHA256SUMS
