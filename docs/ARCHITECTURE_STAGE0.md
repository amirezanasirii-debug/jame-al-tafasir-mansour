# معماری و ممیزی مرحلهٔ صفر

تاریخ بررسی: ۲۰۲۶-۱۰-۱۳

## معماری واقعی

| بخش | پیاده‌سازی فعلی |
|---|---|
| رابط مشترک | React 19 + Vite 6، فارسی و RTL |
| Android | Activity جاوا با WebView محدودشده و دارایی‌های محلی؛ minSdk 24 |
| Windows | Electron با sandbox، context isolation و پروتکل محلی |
| ناوبری | state داخلی React؛ Compose و Navigation Compose استفاده نشده‌اند |
| محتوای پایه | JSON فقط‌خواندنی در `public/content.json` |
| دادهٔ کاربر | localStorage با Export/Import نسخه‌دار JSON |
| شبکه | برای مطالعهٔ محتوای پایه لازم نیست؛ cleartext در Android خاموش است |

انتخاب رابط مشترک به این دلیل حفظ شده که Android و Windows از یک کد UI و یک رفتار آفلاین استفاده کنند. مهاجرت به Compose/Room یک بازنویسی مستقل Android است و با نسخهٔ Windows کد مشترک نخواهد داشت.

## نتیجهٔ ممیزی منشأ

| مورد | محل سابق | ریسک | اقدام |
|---|---|---:|---|
| بسته‌های تفسیر و ترجمه با منشأ نرم‌افزار ثالث | `public/offline/tafsir` و `release/data-packs` | بحرانی | خارج از پروژه قرنطینه شد |
| بستهٔ حدیث و پیوند آیات | `public/offline/hadith` و `public/offline/similarity` | بحرانی | قرنطینه؛ مشابه‌یاب با الگوریتم مستقل جایگزین شد |
| واژه‌نامهٔ استخراج‌شده | `public/vocabulary.json` | بحرانی | قرنطینه؛ UI بدون داده تا منبع مجاز باقی ماند |
| صوت با شرایط بازتوزیع تأییدنشده | `public/audio` | بالا | قرنطینه؛ پلیر به وضعیت «در انتظار بستهٔ مجاز» تغییر کرد |
| فایل‌های مرجع، PDF و اسکریپت‌های استخراج | `reference-sources`، `assets/archive` و اسکریپت‌های ورود اختصاصی | بحرانی | قرنطینه شد |
| نام‌ها و شناسه‌های داخلی وابسته | React/CSS/tests/docs | بالا | حذف یا با نام عمومی «source» جایگزین شد |
| آیکون دارای عنوان منابع | assets، public و mipmapهای Android | بالا | قرنطینه؛ آیکون مستقل جایگزین می‌شود |
| خروجی‌های build قدیمی | `dist`، `build`، `android/build` و `release` | بالا | قرنطینه؛ فقط از سورس پاک‌سازی‌شده بازتولید می‌شود |

قرنطینه قابل‌بازیابی است و داخل مخزن یا خروجی عمومی قرار نمی‌گیرد.

## قابلیت‌های موجود

- جست‌وجوی دامنه‌دار قرآن، ترجمه و تفسیر؛ تاریخچه و پرش مستقیم.
- نشان‌گذاری با دسته‌های ساده و ادامهٔ مطالعه.
- یادداشت غنی متصل به آیه، جست‌وجو، اشتراک و پشتیبان JSON.
- تنظیم فونت/اندازه، تم روشن/تاریک و نمایش RTL.
- کتابخانهٔ تفاسیر با انتساب و حالت مقایسه برای دو منبع نصب‌شده.
- حالت‌های Empty/Error برای بسته‌هایی که هنوز منبع مجاز ندارند.

## محدودیت ثبت‌شده

FTS5 و Room در معماری فعلی وجود ندارند. جست‌وجوی نسخهٔ پایه در حافظه و خارج از متن نمایشی انجام می‌شود. اضافه‌کردن SQLite/FTS5 برای بسته‌های بزرگ در فاز بسته‌های دانلودی انجام می‌شود؛ بدون تغییر نص یا دادهٔ نمایشی.
