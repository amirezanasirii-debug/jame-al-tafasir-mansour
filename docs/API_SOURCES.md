# سرویس‌های برخط و سیاست ورود آفلاین

آخرین بازبینی: ۲۰۲۶-۱۰-۱۴

این سرویس‌ها وابستگی زمان اجرای مطالعه نیستند. نسخهٔ انتشار باید قرآن، ترجمه،
تفسیر، دعا و حدیث نصب‌شده را از بسته‌های محلی بخواند. سرویس برخط فقط برای
جست‌وجوی اختیاری یا ساخت بسته توسط ابزارهای توسعه استفاده می‌شود.

| سرویس | استفاده | کلید | وضعیت بازتوزیع |
|---|---|---:|---|
| AlQuran Cloud API v1 | دریافت `quran-simple` و `fa.fooladvand` | ندارد | شرایط خود سرویس و شرایط ویرایش/مترجم باید در بسته حفظ شود؛ نص بدون تغییر |
| fawazahmed0/hadith-api `@1` | دریافت اختیاری یک حدیث از ویرایش مشخص | ندارد | کد/مخزن Unlicense است، اما منشأ و مجوز متن هر ویرایش باید جداگانه احراز شود |
| Thaqalayn API v2 | بازیابی اختیاری حدیث با شناسهٔ کتاب/حدیث | ندارد | کد API GPL-3.0 است؛ داده از منبع بالادستی گردآوری شده و بدون احراز متن/ترجمه در بسته عمومی قرار نمی‌گیرد |
| Crossref REST API | متادیتای استنادی (عنوان، نویسنده، سال، DOI) | ندارد | فقط متادیتای لازم ذخیره می‌شود؛ چکیده و متن مقاله دانلود نمی‌شود |
| Semantic Scholar Graph API | جست‌وجوی اختیاری پژوهشی | اختیاری | غیرفعال پیش‌فرض؛ فعال‌سازی نیازمند پذیرش شرایط جاری و بررسی نوع استفاده است |

## کنترل‌های فنی

- فقط HTTPS و دامنه‌های allowlist شده مجازند.
- timeout، retry محدود، بررسی status و اعتبارسنجی شکل پاسخ اجباری است.
- ورودی شناسه‌های کتاب/ویرایش در برابر path traversal محدود شده است.
- هیچ API key یا token در کد، APK، نصب‌کننده یا Git نگهداری نمی‌شود.
- واردکننده‌ها ابتدا فایل موقت می‌سازند و پس از اعتبارسنجی/هش/بررسی SQLite آن را جایگزین می‌کنند.
- رایگان یا بدون کلید بودن API به‌معنای اجازهٔ بازتوزیع همهٔ متون آن نیست.

## دعاها

اسکیمای `jame-mansour-dua` نسخهٔ ۱ برای تطبیق خط‌به‌خط عربی و فارسی پیاده شده
است. هر بسته باید URL منبع، نام و URL مجوز، نسخه و تاریخ دریافت داشته باشد.
در تاریخ این بازبینی، مخزن عمومی پیدا‌شده برای دعای کمیل فایل LICENSE روشن
نداشت؛ بنابراین هیچ متن حدسی یا بدون شناسنامه وارد `public/data/duas` نشده است.
فایل موجود در `tests/fixtures` صرفاً دادهٔ غیردینیِ ساختگی برای تست است و در
خروجی انتشار بسته‌بندی نمی‌شود.
