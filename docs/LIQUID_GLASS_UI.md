# Mansour Liquid Glass UI 3.0

نسخهٔ اندروید یک پوستهٔ بومی Jetpack Compose دارد که رابط آفلاین موجود را بدون بازنویسی منطق محتوا در خود نگه می‌دارد. نوار بالا، نوار پایین پنج‌تب و Drawer سمت راست بومی هستند؛ صفحات قرآن، تفاسیر، حدیث، واژه‌نامه و یادداشت‌ها همچنان از پایگاه‌های داده و منطق تثبیت‌شدهٔ برنامه استفاده می‌کنند.

## اجزای بومی

Design System در مسیر `android/src/main/kotlin/org/jamealtafasir/mobile/ui/designsystem/glass/` قرار دارد و شامل Surface، Card، Button، SearchField، TopBar، BottomNavigation، ModalDrawer، Dialog، BottomSheet، Dropdown، Theme و Animation است.

- پالت رسمی زمردی/طلایی و تم روشن و تاریک در `GlassTheme.kt` ثبت شده است.
- حداقل سطح لمس ۴۸dp رعایت می‌شود.
- نوار پایین با IME جابه‌جا می‌شود و روی صفحه‌کلید قرار نمی‌گیرد.
- دستگاه کم‌حافظه یا Battery Saver به‌صورت خودکار حالت کم‌هزینه می‌گیرد.
- خاموش‌بودن انیمیشن‌های سیستم در Native shell رعایت می‌شود.

## محدودیت فنی شیشه

Compose به‌تنهایی نمی‌تواند پیکسل‌های پشت یک `AndroidView` را مانند backdrop-filter نمونه‌برداری کند. بنابراین سطوح بومی از fallback چندلایهٔ صادقانه شامل tint، گرادیانت پویا، لبهٔ روشن و سایهٔ نرم استفاده می‌کنند و فرزندان خود را محو نمی‌کنند. داخل محتوای WebView، روی نسخه‌های پشتیبانی‌شدهٔ Chromium، `backdrop-filter` واقعی فعال است و برای نسخه‌های فاقد پشتیبانی fallback مات وجود دارد.

## خوانایی

صفحهٔ مصحف و متن آیات روی سطح کرم و مات باقی مانده است. Blur سنگین برای هر کارت فهرست استفاده نمی‌شود و قابلیت کاهش حرکت سیستم نیز رعایت شده است.
