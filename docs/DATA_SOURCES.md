# منابع داده و تصمیم انتشار

آخرین بازبینی: ۲۰۲۶-۱۰-۱۵. وجود یک مخزن عمومی، API یا برچسب مجوز روی کد به‌تنهایی مجوز متن کتاب‌ها نیست.

## بستهٔ کامل آفلاین ۲.۷.۰ (بازسازی پایدار بر پایهٔ ۲.۴)

صاحب پروژه اعلام کرده است که برای تبدیل و استفاده از متن منابع نصب‌شده اجازه گرفته است. این اجازه توسط فرایند Build قابل راستی‌آزمایی حقوقی نیست؛ بنابراین مسئول نگهداری مستند اجازه و پاسخ‌گویی انتشار عمومی، صاحب پروژه است. در تبدیل انجام‌شده فقط متن علمی، پیوند آیه و شناسنامهٔ کتاب استخراج شده و هیچ کد، رابط، تصویر یا نشان نرم‌افزار مرجع وارد پروژه نشده است.

## در انتظار اجازهٔ رسمی ناشر/دارندهٔ حقوق

برای منابعی خارج از فهرست بستهٔ کامل بالا، فقط اسکریپت ورود عمومی و اسکیمای بسته آماده می‌شود تا منشأ و اجازهٔ آن جداگانه تعیین شود. ادعای صاحب پروژه دربارهٔ اجازهٔ منابع بستهٔ کامل ثبت شده است؛ این سند جایگزین مدرک حقوقی ناشر نیست.

## سیاست بسته‌های آفلاین

- متن قرآن، ترجمه و تفسیر پایه داخل نصب‌کننده‌اند و بدون اینترنت کار می‌کنند.
- هر منبع بزرگ، پوشهٔ مستقل با شناسه، مؤلف، نسخه، اندازه و SHA-256 قطعه‌ها دارد.
- دانلود ابتدا در فایل موقت انجام می‌شود؛ پس از بررسی هش و اسکیمای SQLite به‌صورت اتمیک فعال می‌شود.
- خروجی کامل حجیم است؛ فایل‌های تولیدی در Release نگه‌داری می‌شوند و داخل تاریخچهٔ Git قرار نمی‌گیرند.
- اطلاعات کاربر از بسته‌های محتوا جدا می‌ماند تا حذف یا به‌روزرسانی منبع، یادداشت‌ها و نشان‌ها را پاک نکند.
