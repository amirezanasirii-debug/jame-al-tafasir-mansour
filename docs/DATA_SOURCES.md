# منابع داده و تصمیم انتشار

آخرین بازبینی: ۲۰۲۶-۱۰-۱۳. وجود یک مخزن عمومی، API یا برچسب مجوز روی کد به‌تنهایی مجوز متن کتاب‌ها نیست.

جزئیات سرویس‌های برخط و سیاست تبدیل آن‌ها به بستهٔ مستقل در
[`API_SOURCES.md`](API_SOURCES.md) ثبت شده است.

## در انتظار اجازهٔ رسمی ناشر/دارندهٔ حقوق

برای تفاسیر و ترجمه‌های معاصر یا نسخه‌های چاپی دارای ناشر، فقط اسکریپت ورود عمومی و اسکیمای بسته آماده می‌شود. خود متن تا دریافت فایل منبع و اجازهٔ قابل‌استناد وارد نسخهٔ عمومی نخواهد شد. اجازهٔ شفاهی برای زنجیرهٔ انتشار عمومی، فروشگاه‌ها و GitHub Releases کافی تلقی نمی‌شود.

## سیاست بسته‌های آفلاین

- متن قرآن، ترجمه و تفسیر پایه داخل نصب‌کننده‌اند و بدون اینترنت کار می‌کنند.
- هر منبع بزرگ، فایل مستقل با شناسه، مؤلف، نسخه، URL، مجوز، اندازه و SHA-256 خواهد داشت.
- دانلود ابتدا در فایل موقت انجام می‌شود؛ پس از بررسی هش و اسکیمای SQLite به‌صورت اتمیک فعال می‌شود.
- فایل‌های حجیم وارد Git نمی‌شوند و فقط در Release/CDN عمومی بدون توکن خصوصی منتشر می‌شوند.
- اطلاعات کاربر از بسته‌های محتوا جدا می‌ماند تا حذف یا به‌روزرسانی منبع، یادداشت‌ها و نشان‌ها را پاک نکند.
