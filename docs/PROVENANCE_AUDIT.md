# گزارش ممیزی انتشار عمومی

این گزارش ثابت می‌کند خروجی عمومی فقط از سورس پاک‌سازی‌شده ساخته می‌شود.

## معیارهای ممیزی

- نبود فایل استخراج‌شده از نرم‌افزارهای دیگر.
- نبود نام، لوگو، آیکون، متن رابط یا شناسهٔ داخلی وابسته به محصول ثالث.
- ثبت نام اثر، مؤلف، نسخه، منبع و شرایط استفاده برای هر محتوای باقی‌مانده.
- نبود keystore، رمز، token، فایل نصب قدیمی یا خروجی build در مخزن.
- ممنوعیت اسکرپ انبوه و ورود خودکار دیتاست‌های دارای مجوز مبهم.

## نتیجه

داده‌ها و خروجی‌های قدیمی به قرنطینهٔ خارج از پروژه منتقل شدند. نسخهٔ پایه فقط شامل متن Tanzil و دو منبع QuranEnc است. بخش‌های تفسیر تکمیلی، حدیث، واژه‌نامه و صوت تا ورود بسته‌ای با شناسنامهٔ معتبر، حالت خالی شفاف نمایش می‌دهند.

پیش از هر Release، آزمون `tests/offline.test.js` نبود پوشه‌های قدیمی و صحت شمارش محتوای پایه را کنترل می‌کند.
